# Fonts

These files are subsets (Basic Latin plus a few punctuation marks) embedded into the profile SVGs.

- `display-600.woff`: Lora SemiBold, by Cyreal. SIL Open Font License 1.1. https://github.com/cyrealtype/Lora-Cyrillic
- `sans-400.woff`, `sans-700.woff`: TeX Gyre Heros Regular and Bold, by GUST e-foundry. GUST Font License. https://www.gust.org.pl/projects/e-foundry/tex-gyre

`widths.json` holds each font's character widths so the build script can lay out text without extra libraries.
