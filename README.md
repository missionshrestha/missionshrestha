I'm a software engineer from Kathmandu who likes owning a problem from start to finish. Over the last few years I've moved from frontend work for an Australian team, to data engineering for enterprise retail clients, to building and leading a multi-tenant SaaS platform. Each step taught me a different layer of the stack, and I enjoy working across all of them.

If there's a pattern to how I work, it's that I'd rather learn the unfamiliar thing than route around it.

## How I work

**I learn the unfamiliar thing.** Cryptography, Spark tuning, compiling Python to C, SEO: I knew none of them when the work needed them.<br>
**I measure before I claim.** I check results against ground truth and report the real numbers, even when they miss the target.<br>
**I explain things simply.** Documentation, articles and mentoring are how I find out what I only half understand.<br>
**I build with AI and own the result.** I work in agentic workflows with Claude Code and Cursor. Framing, decisions and verification stay with me.
