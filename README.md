## Selected work

- **Plain-English to SQL.** An assistant that writes runnable SQL from a question. The model only ever sees the database's structure, never its data or credentials. In production.
- **[api-connector](https://github.com/missionshrestha/api-connector).** Connects to external APIs with six sign-in methods including both OAuth2 flows, detects their schema and previews live data. React and TypeScript on a Django API. Open source.
- **A smaller cloud bill.** Right-sizing, idle-resource cleanup and scheduled start/stop on Step Functions, Lambda and EventBridge took a monthly AWS bill from $773 to $175 in two months.
- **Faster queries.** A 29-minute warehouse query down to 14, and a 15-second API response down to under 6, by finding where the time actually went.
- **[Signed offline licensing](https://github.com/missionshrestha/poc-license-server).** An issuing server and an [offline client](https://github.com/missionshrestha/poc-offline-client) that verify Ed25519 signatures and reject tampered licence files. Open source.
- **Job orchestration.** Scheduled pipeline runs with dependencies, conditional routing and cancellation, on Celery and Redis. In production.
